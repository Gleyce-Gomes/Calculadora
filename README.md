# 🧮 Calculadora

Uma calculadora simples feita com **HTML**, **CSS** e **JavaScript**, que permite realizar operações básicas de soma, subtração, multiplicação e divisão entre dois números.

## 📸 Pré-visualização

![Calculadora](Foto%20-%20Calculadora.png)

## 🔗 Acesse o site aqui:
https://gleyce-gomes.github.io/Calculadora/

## 🚀 Funcionalidades

- Inserir dois números.
- Escolher uma operação:
  - Somar (+)
  - Subtrair (-)
  - Multiplicar (×)
  - Dividir (÷)
- Exibir o resultado automaticamente ao clicar em **Calcular**.
- Validação para evitar divisão por zero.
